科研工作者Researchers

读论文、做批注、整理讲义 —— 一天要重复十遍。 Read, annotate, write up — ten times a day.

  • 批注写回 PDF 文件本身：高亮 / 下划线 / 删除线 / 图形 / 文本框 / 指示批注都能存回文件，换个阅读器打开也看得见。文本框自动换行、高度自适应，选中后能像画图软件一样拖动位置、拖左右边改宽度。 Annotations saved into the file: highlight, underline, strike-out, shapes, text boxes and callouts are written back, visible in any reader. Text boxes wrap and auto-fit, and once selected can be dragged or resized by their left/right edges.
  • 论文速读 / 精读：一键得到「核心贡献 / 实验与可信度 / 局限与坑 / 值不值得精读 / 复现检查清单」，精读再补 Mermaid 图与逐节审校；按文档 ID 缓存，同一篇不重复花 token。 Paper quick-read / deep-read: contribution, evidence, limits, verdict and a reproduction checklist — deep-read adds Mermaid figures and a per-section review. Cached per document, so the same paper never costs twice.
  • 公式与图就是排版好的：Markdown 里写 \(…\)、\[…\] 和 mermaid 代码块，预览里直接出公式与流程图。 Maths and diagrams, typeset: write \(…\), \[…\] or a mermaid block in Markdown and the preview renders formulas and flowcharts.
  • 一集课程 → 一篇讲师级讲义：本地 whisper 转写 + 三阶段成文，结尾自动带课后总结、学习检查清单、思考题、实验设计；写到一半关掉也能续。 A lecture becomes a long-form handout: local whisper plus a three-stage writer, ending with a summary, self-check list, questions and lab design; stop halfway and it resumes.

学生Students

外语课听不懂、课程太散、笔记永远没整理。 Lectures too fast, notes never written up.

  • 外语课实时出中文字幕：内置浏览器打开视频页点「字幕」；转写在本机跑（音频不出电脑），译文整篇一次到位；字幕条可拖拽、可停靠。 Live Chinese subtitles for a foreign-language lecture: open the video in the built-in browser and press Subtitles; transcription runs locally (audio never leaves the machine) and the translation arrives in one pass; the overlay is draggable and dockable.
  • 把一集课变成能复习的讲义：右键「生成文章」→ 标题 / 概述 / 小节 / 总结，公式与图都补齐；没写完关掉也行，回来自动接着写。 Turn a lecture into revision material: right-click Generate article → title, overview, sections, summary, with formulas and figures filled in; unfinished work resumes next time.
  • 笔记就是 Markdown：边写边预览，公式、表格、Mermaid 都渲染；工作区树里随手建文件夹，全局搜索支持正则和 glob。 Notes are just Markdown: live preview with formulas, tables and Mermaid; build folders in the workspace tree; global search with regex and glob.
  • 轻到可以装在老笔记本上：主程序 2.5 MB，装完即用；不用的插件可以禁用 —— 不看 PDF，PDF 就完全不加载。 Light enough for an old laptop: a 2.5 MB main binary, works right after install; unused plugins can be disabled — no PDF reading, no PDF loaded.

工程技术人员Engineers & technicians

看手册、连设备、翻日志、改远程文件 —— 工具散在五个软件里。 Manuals, devices, logs and remote files — spread across five programs.

  • 终端就在编辑器底部：PuTTY 会话（串口 / SSH / Telnet）以标签页停靠在下侧，会话配置独立存储，不动系统里那份。 A terminal docked under the editor: PuTTY sessions (serial, SSH, Telnet) live in bottom tabs; their profiles are stored separately and leave your system PuTTY alone.
  • WSL 与远程文件跟本地一样：wsl:// 挂进工作区树后，打开、编辑、保存、搜索、另存为全程一致 —— 因为文件系统本身就是插件。 WSL and remote files behave like local ones: mount wsl:// into the tree and open, edit, save, search and Save-As all work the same — the file system itself is a plugin.
  • 手册和图纸能批注：批注存回 PDF，发给同事照样看得见；几百页的手册不卡（页级缓存、可见页裁剪、关档整块把内存还给系统）。 Manual and drawing annotation: annotations go back into the PDF and survive sharing; hundreds of pages stay smooth (page caches, visible-page culling, whole arena returned on close).
  • 日志分频道、可过滤：构建与插件的日志进底部输出栏，按频道分开、按级别过滤；图片查看器能缩放、平移、调亮度对比度、裁剪，不改原文件。 Logs per channel, with levels: build and plugin logs land in the bottom output pane, split by channel and filterable by level; the image viewer zooms, pans, adjusts and crops without touching the original.

程序员Programmers

想要「起得快、改得动、能扩展」的编辑器，而不是再装一套 Electron。 An editor that starts fast, can be changed, and can be extended — without another Electron runtime.

  • 启动快得能解释：启动只读清单建菜单，一个插件都不加载、一个 WebView2 都不创建；面板和视图第一次显示才装载（收起状态下实测 0 个 WebView2 进程）。 Startup you can explain: manifests build the menus, zero plugins loaded and zero WebView2 processes created; panels and views load the first time they are shown.
  • 插件体系是"按需装载"的：装了几个插件都行，启动时不加载任何一个 —— 点哪个功能才拉起哪个 DLL，不用的插件连内存都不占；插件在应用内在线安装、更新、禁用。 Plugins load on demand: install as many as you like — none are loaded at startup; a DLL comes up only when you use its feature, and plugins install, update and disable from inside the app.
  • 零 Node 的运行时：C++20 + 纯 Win32 单 exe，不拖 Electron / Node / Python；2.5 MB 主程序 + 静态运行库，装完就一个目录。 A zero-Node runtime: C++20 and pure Win32 in a single exe — no Electron, Node or Python; a 2.5 MB binary plus statically linked runtime in one folder.
  • 编辑器该有的都有：按扩展名选词法器（Lexilla）、正则与跨行查找替换、多根工作区、标签分栏、深色自绘界面（无边框窗口、自绘菜单，跟随主题）。 The usual editor things, done properly: lexer per extension (Lexilla), regex and multi-line search & replace, multi-root workspace, split tabs, and a fully owner-drawn dark UI that follows the theme.

四类人用的是同一个程序：装哪个插件、开哪个面板，自己定。集成显卡也跑得动，离线也跑得动。 All four use the same program — which plugins and panels you enable is up to you. It runs on integrated graphics and it runs offline.

浏览器插件：自动字幕 → 自动翻译 → 字幕成文The browser plugin: auto subtitles → auto translation → subtitle-to-article

看外语课程最费时间的是「听懂」和「整理」。这条流水线把两件事都做掉：一键得到中文字幕，右键再把它整理成一篇长讲义。 Understanding and organising a foreign-language lecture is the slow part. This pipeline does both: subtitles in one click, then a long-form article from the right-click menu.

  1. 1取音源Fetch audio — 站点脚本认领播放页，取音源后在页面内解码成 16 kHz 单声道；超长音频按分片表切窗口逐段解码再拼。A site script claims the player page; audio is decoded in-page to 16 kHz mono; very long audio is decoded window-by-window and stitched.
  2. 2本地转写Local transcription — 8 分钟分段交给本机 whisper（CPU 能跑，N 卡自动走 CUDA）；音频不出本机，模型应用内一键下载。8-minute segments go to local whisper (CPU or CUDA); the audio never leaves the machine, models download in-app.
  3. 3整篇翻译 / 只校对Translate or proofread — 整篇字幕一次发给 DeepSeek（格式锁死：不漏条、不动时间轴）；中文音频只校对不翻译。The whole transcript goes out in one call (schema locked); Chinese audio is proofread only, never translated.
  4. 4字幕成文Subtitle-to-article — 右键「生成文章」：筋骨 → 血肉 → 逐节审校 → 概述/总结 → 总分总组装，一篇可读的长文就出来了。Right-click “Generate article”: skeleton → flesh → per-section review → overview & summary → assembled whole.

成文是有规矩的Writing with rules

规范从「字幕 ↔ 范文讲义」对照样本里提炼：4 级标题、固定尾节（课后总结 / 检查清单 / 思考题 / 实验设计）、段落模板、扩写比例。Rules distilled from transcript↔model-lecture pairs: 4-level headings, a fixed tail (summary, self-check, questions, lab design), paragraph templates, expansion ratio.

不重跑、能接着写Resume, never redo

已完整的字幕/文章不重跑；没完整的按覆盖点续转、按检查点续写；离开页面 / 关标签就停，回来接着干。Finished subtitles and articles are never redone; partial work resumes from coverage and checkpoints; leaving stops the jobs, returning continues them.
