# TruthPad 用户手册

> 轻量、快速、插件化的开发编辑器 —— C++20 + 纯 Win32 + Scintilla，主程序 9.1 MB 单 exe，
> 不依赖 Node.js / Electron / Python。本手册对应当前 Beta 渠道版本（「帮助 → 关于 TruthPad」显示 0.2.1）。
>
> **读法约定**：`视图 → Markdown 实时预览` 表示菜单路径 —— 菜单从左上角的汉堡按钮 ☰ 弹出；
> `Ctrl+F` 表示快捷键；`> 🖼️ 【插图 x-y】` 是**待补的截图占位**（全部清单见附录 D），
> 正文不依赖图片也能读懂。

## 1. Highlight：五个亮点

### 1.1 右键打开文件 = 极简模式，毫秒级

安装包注册的文件关联命令是 `TruthPad.exe --quick "%1"`。右键（或双击）一个文本文件选 TruthPad 时：

- **不恢复上次的工作区**（侧栏、终端、AI 面板都不显示）；
- **不会多出一个空的「未命名」标签** —— 只为尽快看到并编辑这个文件；
- 极简启动只影响本次会话，**不改动 `config.ini`**，下次正常启动照旧恢复工作区。

实测（仓库验收数据）：热启动到窗口 **< 200 ms**，冷启动（含文件加载）**< 700 ms**，
空闲内存约 16 MB。

双击 exe（或命令行不带文件）仍是完整界面：会打开一个自绘的「欢迎」页。想手动极简启动就自己加 `--quick`。

如果你是用 Windows「打开方式 → 选择其他应用」手动关联的（那种条目只有 `"%1"`、没有 `--quick`），
右键打开会退化成完整界面 —— 菜单 **帮助 → 修复右键打开关联** 会把它修成 `"<exe>" --quick "%1"`
（只写当前用户，不需要管理员）。

> 🖼️ **【插图 1-1】** 极简模式：右键一个 `.md` 文件打开，界面只有该文件一个标签（无侧栏、无欢迎页、无未命名标签）

### 1.2 大文件 Markdown 渲染 + 自带导出 PDF / HTML

- **大文件不卡编辑**：编辑器对 4 MB 及以上的文档**自动关闭语法着色**以省内存（状态栏提示
  「大文件：已关闭语法着色（省内存）」）；预览渲染跑在独立的 WebView2 进程里，输入到重渲染
  有 250 毫秒防抖，不会在敲字时拖住界面；Mermaid 图表引擎只在文档**真的含 mermaid 代码块**时才加载。
- **自带导出**：在编辑器、预览区或右栏预览的**右键菜单**里点「生成 PDF」或「生成 HTML」，
  产物落在**源 md 同目录、同名**（`报告.md → 报告.pdf / 报告.html`，已存在直接覆盖）。
  PDF 为 A4 纵向、上下边距 17 mm、左右 16 mm、打印背景图形、无页眉页脚、强制浅色主题；
  HTML 是单文件（内嵌样式、Mermaid 已转为 SVG、图片路径绝对化），可直接分发。

> 🖼️ **【插图 1-2】** 一个含公式与 Mermaid 图的 Markdown：左侧源码、右侧实时预览，右键菜单里的「生成 PDF / 生成 HTML」

### 1.3 所有附加功能按需延迟加载，保持轻量

- **启动不加载任何插件 DLL**：只读纯文本清单（或从 DLL 里以"数据模式"读内嵌清单，不执行代码），
  把命令预建进菜单，点到才加载。
- **面板与网页视图"用到才建"**：左栏插件视图、底边栏插件页签、右侧 AI 面板（你**真的用过**它之后才装载）、
  以及所有 WebView2（设置页 / 插件页 / Markdown 预览 / 右栏预览 / 浏览器）都在第一次需要时才创建。
- 实测：收起右侧面板时启动 **0 个 `msedgewebview2` 子进程**；仓库里有专门的回归脚本盯着这一条。

> 🖼️ **【插图 1-3】** 插件管理页：每个插件声明自己的能力和加载方式（懒加载 / 禁用 / 卸载）

### 1.4 PDF 阅读器 + AI 速读 / 精读

- **批注**：下划线、删除线、文字高亮、区域高亮、自由高亮、直线/矩形/椭圆/云朵/多边形/自由笔、
  文字批注/文本框/指示批注/便签 —— 配 50 步撤销栈，并能**保存回 PDF 原文件**。
- **论文速读 / 论文精读**（状态栏最右两个按钮，用共享的 AI 模型）：

  | | 论文速读 | 论文精读 |
  | --- | --- | --- |
  | 目的 | 帮你决定**值不值得花时间读** | 帮你**读完就真懂** |
  | 篇幅 | 克制（1500–3000 字，不是摘要） | 上不封顶，禁止注水 |
  | 内容 | 骨架要点、术语讲人话、核心公式给直觉 | 补前置知识、点名关键引用、公式逐符号解释、必要处配 Mermaid 图 |

- 产物落 `文档\TruthPad\PDF\<PDF名>-<文档标识hash8>-speedread.md`（精读是 `-deepread.md`），
  完成后直接开在右侧「预览」页签。**同一份文档第二次点 = 命中缓存，0 次模型调用** ——
  身份认的是 PDF 内嵌的文档标识，**给 PDF 加批注、加书签不会让它变成"新文档"**。

> 🖼️ **【插图 1-4】** PDF 阅读器：左栏缩略图、工具栏、批注，以及右侧「预览」页签里正在生成的速读稿

### 1.5 浏览器插件：为视频生成字幕 → 翻译成中文 → 生成讲义

- 在内置浏览器里打开视频页（bilibili 已验证完整链路），点工具栏的「字幕」：
  **本地 whisper 逐段转写**（模型在应用内一键下载，**音频不出本机**），字幕栏浮在页面上显示原文。
- 整集转完发给 DeepSeek：外语音频**翻译成中文字幕**；中文音频**只校对**（纠识别错、公式记号规范化）。
- 右键「生成文章」：把整集字幕整理成一篇**长讲义**（公式补全、Mermaid 配图、结尾带总结/检查清单/思考题）。
  **写作模式按视频内容自动判型**（学术讲义 / 小清新 / 新闻纪实），也可以手动指定。
- 已经生成过的直接打开（0 次调用）；没写完的**接着写**（断点续生成）。

## 2. 文本编辑器（主程序）

### 2.1 安装与启动

- **安装包**是自绘的一键安装器（深色窗口 + 一个按钮），装到 `%LOCALAPPDATA%\Programs\TruthPad`，
  不需要管理员、不用重启；会创建开始菜单快捷方式、可选的桌面快捷方式、`*.truthpad.json` 文件关联，
  并在「设置 → 应用」里登记卸载项。卸载会删除程序文件、快捷方式与文件关联，
  `%APPDATA%\TruthPad` 里的设置与最近记录会保留。
- **命令行**：`TruthPad.exe [--quick] <文件或项目 …>`。以 `-` 或 `/` 开头的其它参数会被忽略；
  以 `.truthpad.json` 结尾的参数按项目文件打开，其余按普通文件打开。
- **启动位置**：出现在光标所在那块显示器的工作区正中（多屏时"在哪块屏启动就在哪块屏出现"），
  并被夹住不被任务栏压住。
- **欢迎页**：正常启动（没给文件）时打开 —— 「开始」四张卡片（新建文件 / 打开文件 / 打开文件夹 / 打开项目）、
  最近打开、常用快捷键。关掉它、以及关掉**最后一个**标签，都**不会**自动补一个空白文档；
  一个标签都不剩时编辑区显示空状态提示（插图 + 快捷键），**双击空白处 = 新建文件**。

> 🖼️ **【插图 2-1】** 欢迎页：开始卡片、最近打开、快捷键三块

### 2.2 界面总览

- **自绘标题栏**：左侧是汉堡菜单 ☰ 和「TruthPad — 项目名」；右侧三个布局按钮
  （左侧栏 / 底部终端 / 右侧 AI 面板，填充=显示、空心=隐藏）以及最小化 / 最大化 / 关闭。
  标题栏空白处可拖动窗口、双击最大化。
- **左栏**：44 px 图标轨常显（「项目」文件树与「搜索」两个内置项在前，插件项按优先级排在后面），
  点图标展开侧栏并切到该面板；收起侧栏走标题栏按钮或 `Ctrl+B`。
- **编辑区**：标签栏 + 编辑器（行号、折叠、按扩展名自动选择词法着色）。
- **底部面板**：会话页签 + 「输出」页签（Ctrl+` 显示/隐藏）。
- **右侧面板**：两个页签 —— 「预览」（插件生成的内容都开在这里）与「AI」。
- **状态栏**：左侧依次是消息、行/列（有选中时显示选中字数）、语言、编码、行尾；
  右侧是插件按钮（如 PDF 的速读/精读）、以及最右端「状态栏收进左侧栏（点击）」的双箭头按钮。

### 2.3 标签与分栏

- **标签**：带脏点（未保存）标记；鼠标中键点标签 = 关闭；标签条空白处双击 = 新建文件；
  标签条上滚滚轮 = 横向滚动标签。
- **标签右键菜单**：关闭 / 关闭其他 / 关闭右侧标签 / 向右分栏 / 向下分栏。
- **编辑区最多分 4 块**（横竖都可以）：
  - 拖动标签到某一块的**边缘 25% 内** = 在那一块的这个方向新分一块；
    拖到某一块的**中间 50%** = 把标签移进那一块（拖动中有落点提示）；
  - 某块**最后一个标签**被拖走或关掉 → 这块自动取消分栏，兄弟块顶上来铺满；
  - 每块有独立标签栏和各自可拖的分割条；**点进哪一块，焦点就到哪块** ——
    查找栏、状态栏信息、保存命令都跟着焦点块走。

### 2.4 文件、编码与行尾

- **编码自动探测**：UTF-8（含 BOM）、UTF-16 LE / BE（带 BOM）、合法 UTF-8、系统 ANSI
  （简体中文下即 GBK/CP936）；ANSI 解不出来再按 GB18030 宽松模式解读（状态栏会提示
  「注意：文件编码非标准，已按 GBK 宽松模式解读」）。
- **保存按原编码回写** —— Keil、GCC 工程里的 GBK 源码不会被改成 UTF-8；
  万一编码装不下文件里的字符，会问你「改用 UTF-8 保存吗？」。
- **行尾**（CRLF / LF / CR）原样保留，状态栏只读显示当前值。
- 新建的文档叫「未命名」，第二个起「未命名-2」；关闭有未保存改动的文档会先问一句。

### 2.5 查找 / 替换 / 在文件中搜索

**编辑器查找条**（`Ctrl+F` 查找、`Ctrl+H` 带替换行）：

- 打开时用编辑器里选中的单行文本预填；`Esc` 关闭并回到编辑器。
- 按钮：`▲` 上一个、`▼` 下一个、`Aa` 区分大小写、`W` 全字、`.*` 正则、`⇄` 显示/隐藏替换行、`✕` 关闭。
- 键盘：Enter = 查找下一个，Shift+Enter = 上一个，`F3` / `Shift+F3` 同效；
  替换框里 Enter 执行「替换」。三个选项默认都关。

**左栏「在文件中搜索」**（`Ctrl+Shift+F`，或菜单「视图 → 在文件中搜索」）：

- 输入即搜（450 毫秒防抖）；`Aa` / 「全字」/ `.*`（正则）开关；
  「替换」展开替换行，「筛选」展开「要包含的文件 / 要排除的文件」glob 输入框。
- 结果**按文件分组**（可折叠、带命中数），点任意命中**跳到该行**（整行选中）。
- 「全部替换」会先弹确认（**不可撤销**），跳过"有未保存改动的标签"和无法按原编码回写的文件，
  完成后刷新已打开且不脏的标签。
- 搜索自动跳过 `.git`、`node_modules`、`build`、`dist` 等目录、二进制文件（前 8 KB 含 NUL）、
  超过 4 MB 的文件；UTF-16 文件会提示跳过。单文件最多 200 处、总计 20000 处（超出会提示截断）。
  当前只覆盖**本地**工作区（`wsl://` 等远程根暂不参与）。

### 2.6 工作区树（项目）

面板标题「项目」，可从资源管理器把文件夹直接拖进窗口加为工作区根。

- 头栏按钮：`⊕` 打开文件夹、`⟳` 刷新（快捷键 `F5`，焦点要在树里）。
- 单击文件 = 预览式打开（不固定），双击 = 固定打开；目录双击展开/折叠。
- **多选**：`Ctrl+单击` 加选/减选、`Shift+单击` 区间选、`Ctrl+A` 全选、`Esc` 清空。
- **拖拽移动**：把文件/文件夹拖到目录行即可搬过去（拖动中有跟随光标的半透明小卡片，
  落点高亮；同名或拖进自己里面会被拒绝）。
- **右键菜单**（固定顺序）：

  `打开 / 在文件浏览器中显示 | 拷贝 / 粘贴 | 复制相对路径 / 复制绝对路径 | 新建文件 / 新建文件夹 | 重命名 / 删除`

  工作区根节点的末位是「从工作区移除」（**不会**删磁盘内容）；单选目录时会多一项「展开/折叠」。

- **新建**：先建临时名（「新建文件.txt」/「新建文件夹」，重名自动加 ` (2)`）再就地改名，`Esc` 保留临时名。
- **重命名**：`F2`，Enter 提交、`Esc` 取消、点别处也算认可当前名字；非法名（空、含 `\ / : * ? " < > |`、
  重名、Windows 保留设备名、以点或空格结尾）会被拒绝并保持原名。
- **删除**：`Delete`，**直接进回收站**（无确认；目录递归；已打开的标签一并关闭）。
- **拷贝 / 粘贴**：`Ctrl+C` / `Ctrl+X` / `Ctrl+V`，与资源管理器互通；同名自动 `xxx (2).ext`。
- 远程（`wsl://`）的写操作项会置灰。

### 2.7 终端与输出

- **终端面板**：Ctrl+` 显示/隐藏；新建会话 Ctrl+Shift+T。
- **新建会话对话框**三个页签：
  - **串口**：串口名（自动列出可用端口，默认选第一个）、波特率（115200）、数据位（8）、
    校验（N）、停止位（1）、流控（N）、编码（UTF-8；选 CP936 可正确显示 GBK 中文输出）；
  - **SSH**：主机、端口（22）、用户；认证由 PuTTY 弹框处理（支持密码与密钥）；
  - **本地**：`cmd.exe` 或 `PowerShell`，以独立控制台启动并停靠进面板。
  - 需要官方 PuTTY：放在程序目录 `tools\putty\` 下（找不到会提示）。
- **会话标签右键**：弹出为独立窗口 / 停靠到面板（按当前状态二选一）、关闭会话、新建会话；
  「输出」标签右键：清空当前通道。
- **输出面板**：多通道输出（TruthPad、构建、以及插件自己的频道，例如「PDF」「浏览器」）。
  每行格式为 `时间戳 [模块] [级别]：内容`；页签条最右的「级别：… ▾」按钮选择**最低显示级别**
  （Trace / Debug / Info / Warning / Error / All，默认 Info）。插件第一次写输出时，
  它自己的频道页签会自动出现。面板右键可清空 / 复制全部。

### 2.8 项目文件 `*.truthpad.json`

项目文件可以一次带起多根目录和一套设置（菜单「文件 → 打开项目文件…」，`Ctrl+Alt+O`；
打开过的会进「最近项目」）：

```json
{
  "name": "我的固件工程",
  "folders": [
    "firmware",
    { "path": "../lib", "name": "公共库" }
  ],
  "settings": { "theme": "dark", "defaultEncoding": "utf8", "tabWidth": 4 },
  "wsl": { "distro": "Ubuntu", "remotePath": "/home/me/proj" }
}
```

- `name` 显示在标题栏「TruthPad — 项目名」（缺省取项目文件所在目录名）；
- `folders` 里的相对路径相对项目文件所在目录，可带显示名；
- `settings` 只认 `theme`（dark/light）、`defaultEncoding`（utf8/utf8bom/utf16le/ansi）、
  `tabWidth`（1–16，默认 4）；
- `wsl` 块供 WSL 插件挂载远程目录。

### 2.9 设置（`Ctrl+,`）

左侧六个分区：**外观 / 编辑器 / 终端 / 插件 / 模型 / 关于**。

- **外观**：语言（切换后立即生效）、文件日志级别（Trace 默认 / Debug / Info / Warning / Error，
  低于这一级的日志不写进日志文件，插件日志也照此）、主题（深色 / 浅色，切换立即生效）、
  配色文件（按钮「重新载入配色」「编辑 theme.json」）。
- **编辑器**：字号（当前 14px）、制表宽度（4 空格；项目文件的 `settings.tabWidth` 可覆盖）。
- **终端**：终端提供者（串口/SSH 由 PuTTY 提供）、本地 Shell（cmd.exe / PowerShell，已启用）。
- **插件**：插件目录说明、「管理插件…」按钮，以及「N 个已发现 · M 个已加载」计数。
- **模型**：见 5.5 节 —— 所有 AI 插件共用的一份模型配置。
- **关于**：版本与组件（Scintilla 5.6.7 · Lexilla 5.5.4 · WebView2 · PuTTY）。

### 2.10 主题与配色

- 配色文件在 `%APPDATA%\TruthPad\theme.json`，结构是 `{"dark":{…},"light":{…}}`，
  **逐键覆盖**内置默认（首次启动会自动写出一份带 `_version` 的文件供你改）。
- 内置默认：语法色照 VS Code Dark+/Light+；深色背景不用 `#1E1E1E`，而是 `#111214` 一类的自家灰。
- 改完不用重启：设置页切换，或菜单 **视图 → 重新载入配色**；插件界面会跟着主题一起变。
- 文件写坏不会崩：格式错就退回内置默认，问题记在 `theme.log`。

### 2.11 语言

- 当前提供两门界面语言：**简体中文**、**English (US)**。
- 切换：设置 → 外观 → 语言（菜单、状态栏、插件页面文案一起换，立即生效）。
- 默认跟随系统；语言文件缺失时回落到英语。

### 2.12 插件管理与插件源

- 打开方式：菜单「插件… `Ctrl+Shift+P`」或设置页「管理插件…」。
- 页面分「已安装」与「可用插件」两类；顶部可填**插件源地址**（一个静态目录，里面放
  `index.json` 和各插件包）并「刷新列表」，还有「从文件安装…」「重新扫描目录」「打开插件目录」，
  以及搜索框（按名称 / 作者 / 描述）。
- 每个插件的状态：已加载 / 懒加载 / 已禁用 / 清单异常 / 未安装 / 老式插件 · 随启动加载；
  能力标签：文件 / 远程 / 事件 / 命令 / 面板；类型：查看器 / 工具 / 提供者 / 智能体。

## 3. Markdown 编辑器

### 3.1 打开与三种模式

- 打开一个 `.md` 文件默认是**编辑模式（只显示编辑器）**；插件生成的文档（讲义、速读稿）
  默认「预览模式（只显示预览）」。三种模式互斥：

  | 模式 | 内容 |
  | --- | --- |
  | 编辑模式（只显示编辑器） | 纯写作，最省资源（不建 WebView2） |
  | 分栏模式（左编辑器 / 右预览） | 左边写、右边实时看 |
  | 预览模式（只显示预览） | 专心阅读 |

- 切换入口：编辑器右键菜单 / 预览区右键菜单（当前模式带勾选）；
  主菜单「视图 → Markdown 实时预览 `Ctrl+Shift+M`」在**编辑 ↔ 分栏**之间切换。
- 预览窗顶栏：标题「Markdown 预览」、两个滚动联动箭头、右侧 `✕`（收起预览，回到只编辑器）。
  非 Markdown 文件不会有这些菜单项（会提示「当前文件不是 Markdown，无预览」）。

> 🖼️ **【插图 3-1】** 分栏模式：左源码右预览，预览顶栏的两个联动箭头

### 3.2 预览能渲染什么

预览用 WebView2 渲染，能力等同于一个现代 Chromium 页面：

- **GFM 风格 Markdown**（markdown-it 14.3.2）：表格、任务列表、自动链接；
  单换行**不**折行（要换行请空一行或写行尾两个空格）。
- **标题锚点**与 **`[TOC]` 目录**；预览右上角还有一个 ☰ 按钮，可开一个**目录侧栏**
  （收录 h1–h4，点击平滑跳转、滚动时高亮当前章节；文档没有可用标题时按钮不出现）。
- **代码高亮**（highlight.js 11.12.0）；**Mermaid 图表**（3.4.12）—— 只在文档含 mermaid
  代码块时才加载渲染引擎。
- **数学公式**（KaTeX 0.16.11）：`$…$`、`$$…$$`、`\(…\)`、`\[…\]` **四种写法都支持**；
  公式写错不会炸掉整个页面（渲染为错误提示）。
- **相对路径的图片 / 附件**按文档所在目录解析。

> 🖼️ **【插图 3-2】** 预览效果：公式、Mermaid 图、代码高亮、右上角目录侧栏

### 3.3 滚动联动与光标标记

- 预览顶栏两个箭头按钮：**`→` = 编辑器滚动带动预览**、**`←` = 预览滚动带动编辑器**；
  亮的（主文字色）= 联动，暗的（弱化色）= 断开；**默认两个都开**。打开某一向时，
  立刻按当前可见位置对齐一次。
- 联动按**内容行**锚定（不是整体比例），长文档来回滚也不会越滚越偏。
- 编辑器的光标位置会在预览里画一条竖条，选区会有高亮 —— 两边互相找得到对方。

### 3.4 预览里复制 / 全选

预览区右键菜单有两项基本操作：**复制**（没有选中文本时置灰）与**全选**。
复制会把你选中的正文文本写进系统剪贴板（结果在状态栏回报字数）。

### 3.5 导出 PDF / HTML

- **入口**（三处右键菜单，内容一致）：编辑器右键、预览区右键、右栏「预览」页签右键 →
  「生成 PDF」「生成 HTML」。
- **产物**：源 md **同目录、同名**（`报告.md → 报告.pdf` / `报告.html`），
  已存在就**直接覆盖**（状态栏和输出栏会写明这一点）。
- **PDF 怎么来的**：直接对已排好版的预览页面调用 WebView2 打印 —— 公式已排版、
  Mermaid 已是 SVG，所见即所得。页面设置固定为：**A4 纵向、边距上下 17 mm / 左右 16 mm、
  缩放 100%、打印背景图形（代码块底色保留）、无页眉页脚、强制浅色主题**；正文用
  Arial + 雅黑回落，代码用 Consolas。
- **HTML 是单文件**：内嵌样式、图片路径绝对化（`file:///…`）、Mermaid 内联为 SVG、
  强制浅色；不含页面脚本，所以打开它不会有目录侧栏交互。
- **完成提示**：状态栏 + 输出栏「已生成 PDF：…」；HTML 还会报「（Mermaid N 块 / 图片 M 张）」。
- **限制**：
  - 只支持**已保存到本地**的文件（未命名文档、`wsl://` 远程文件没有"同目录"，会拒绝）；
  - 需要系统的 WebView2 Runtime；老版本 Runtime 不支持"打印成 PDF"时会明确报错；
  - 导出前最多等图片 3 秒；页面 15 秒没响应会报超时；同一时刻只能导一个
    （重复点会提示「正在导出中，请稍候…」）。

> 🖼️ **【插图 3-3】** 右键菜单里的「生成 PDF / 生成 HTML」与输出栏的成功提示

### 3.6 大文件与性能

- 4 MB 及以上的文档自动关闭语法着色（状态栏提示，省内存）；预览渲染在独立进程里做，
  250 毫秒防抖，Mermaid 引擎按需加载 —— 文档再大也不会在敲字时卡住。
- 预览滚动联动按行锚定，长文档不会漂移。

### 3.7 常见问题（Markdown）

- **公式没渲染？** 确认写法是 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 之一；
  `$` 紧贴中文或全角标点时可能被当成普通文本，用 `$$…$$` 或 `\[…\]` 更稳。
- **图片不显示？** 相对路径按**文档所在目录**解析；确认文件真的在那个目录里。
- **导出按钮在哪？** 三个右键菜单里，没有工具条按钮。
- **能改 PDF 的纸张和边距吗？** 当前固定 A4（没有选项对话框）。

## 4. 图片编辑器（图片查看器插件）

### 4.1 打开方式与支持格式

- 双击或右键打开 `.png` `.jpg` `.jpeg` `.bmp` `.gif` `.webp` `.tif` `.tiff` 就走它；
  解不开的图会退回文本/二进制视图（不会假装能看）。
- 也可以用菜单「工具 → 用图片查看器打开…」，或在编辑器里右键「用图片查看器打开」。
- 注意：只取**第一帧**（GIF / WebP 动画不会播放）；单图超过 2 亿像素会拒绝加载。

### 4.2 查看：缩放 / 平移 / 翻页

- **滚轮**以**光标为中心**缩放（约 1.15 倍一格），范围 **2%–3200%**。
- **平移**：按住左键拖动，或中键拖动，或按住空格 + 左键拖动；拖不出边界、不露空白。
- **双击**在「适应窗口 ↔ 1:1」之间切换；工具栏也有「适应窗口（F）」「1:1 实际大小（快捷键 1）」。
- **←/→** 在**同目录、同类扩展名**的图片之间循环翻页（到目录头尾会绕回去）。
- 顶部状态行显示：文件名、宽×高、缩放百分比、亮度/对比度/饱和度、改动时带「●未保存」。

> 🖼️ **【插图 4-1】** 图片查看器：工具栏、状态行与一张放大的截图

### 4.3 调色

亮度 `−/+`（范围 -100% … +100%）、对比度 `−/+`（0.1 … 3.0）、饱和度 `−/+`（0 … 3.0），
每步 5%；「重置调色（R）」一键还原（`Ctrl+R` 同效）。

### 4.4 裁剪与保存

- **裁剪**：点「裁剪：拖动框选（C）」→ 拖动框选区域（状态行提示「拖拽框选裁剪区域，回车应用 / Esc 取消」）→
  `Enter` 应用、`Esc` 取消；框选小于 2×2 像素不生效。**裁剪不可撤销**（再次裁剪是在裁剪结果上继续裁）。
- **保存（S）**：覆盖原文件（先写临时文件再替换；JPEG 以 0.92 质量保存）。
- **另存为…**（工具栏按钮）：可选 PNG / JPEG / BMP，按目标扩展名选编码器
  （也支持 gif / tif / tiff）。

### 4.5 快捷键

| 键 | 作用 |
| --- | --- |
| `F` | 适应窗口（只缩小不放大） |
| `1` | 1:1 实际大小（并居中） |
| `R` / `Ctrl+R` | 重置调色 |
| `C` | 裁剪：拖动框选 |
| `Enter` / `Esc` | 应用裁剪 / 取消裁剪 |
| `S` | 保存（覆盖原文件） |
| 工具栏「另存为…」 | 另存为（宿主占用了 `Ctrl+Shift+S`，这一项没有快捷键） |
| `←` / `→` | 同目录同类图片翻页 |
| 空格 + 拖动 | 平移 |

### 4.6 限制

- 没有右键菜单、没有旋转 / 多图 / 幻灯片；裁剪不可撤销；GIF/WebP 只显示第一帧。
- 窗口窄时工具栏图标会逐档变小，但**不会隐藏按钮**（每个按钮都有悬停提示）。

### 5.1 打开与界面

- 双击任意 `.pdf` 就在编辑器标签里打开（会校验文件头，改名成 `.pdf` 的假文件会退回文本视图）。

  窗口变窄时图标逐档缩小（16 → 9 px），按钮不会丢。
- **底部状态条**：左端是左栏开关和翻页器（首页 / 上一页 / 页码框「n / N」/ 下一页 / 末页）；

  （双击分隔条恢复默认），也可以整个收起。

  查找… / 下一个命中 / 上一个命中）在「工具」菜单里，文案形如「PDF：保存」，
  作用于当前聚焦的那个 PDF 视图。

### 5.2 阅读：滚动 / 缩放 / 查找 / 选字

- **连续滚动**：普通滚轮滚动，`Shift+滚轮` 横向，`Ctrl+滚轮` 缩放（每格 ±15%）。
- **缩放**：范围 10%–800%；工具栏放大 / 缩小按钮每次 ×1.25；

- **查找**：工具栏「查找」按钮（或菜单「PDF：查找…」）。查找条在工具栏下方，右侧按钮

### 5.3 批注：六组工具

工具栏里的工具分为六组（悬停有完整提示，选中工具后状态栏也会说明画法）：

| 组 | 工具与用法 |
| --- | --- |
| 选择 | 拖选文字 / 点批注，不画任何东西 |
| 下划线 | 拖选文字后自动加下划线（跨页选区也支持） |
| 删除线 | 同上，自动加删除线 |
| 高亮批注组 ▾ | **文字高亮**（拖选文字后自动加）、**区域高亮**（拖一个矩形）、**自由高亮**（按住随便涂，像荧光笔）。区域/自由高亮对没有文字层的「图片型 PDF」也能用 |
| 形状批注组 ▾ | **直线 / 矩形 / 椭圆 / 云朵**（拖拽绘制）、**多边形**（点击加点，双击或回车收尾，Esc 取消）、**自由笔** |
| 文字批注组 ▾ | **文字批注**（选中文字后点它 = 挂一条引文便签；在页面上点一下 = 放空便签并弹输入框）、**文本框**（拖一个框，或单击得到默认 180×40 pt 的框）、**指示批注**（从被指示点拖到文字框位置；单击则在指示点右上放一个固定框并自动画指示线）、**便签**（点页面放一个「注」图标，双击编辑） |

- 太小的草稿会按误触丢弃（矩形/椭圆 < 3 pt、直线 < 4 pt、自由笔 < 2 点、多边形 < 3 点）；
  绘制过程中显示虚线草稿，`Esc` 可取消。
- **改色**：工具栏颜色按钮点一下循环预设色；它的 `▾` 菜单是色板 ——
  黄 / 绿 / 蓝 / 粉 / 橙 / 其中还有**自定义**（弹自绘调色盘：色块 + 色相条 + 新旧色预览 + 十六进制读数）。
  选中某条批注时改的是它，否则改「下一个新批注」的颜色。
- **选中批注**后旁边会出现小工具条：**改色 / 编辑 / 删除**。
  「编辑」打开小输入框（Enter 确认、Esc 取消、点别处也算确认）；
  刚建的空文本框/空便签没输入内容就确认/取消，会自动删掉，不留空框。
- **撤销 / 重做**：上限 50 步，覆盖新建 / 删除 / 改色 / 改内容四类；工具栏撤销/重做按钮会相应置灰
  （快捷键说明见 5.7 —— 这两组键被宿主占用，用按钮）。
- 鼠标悬停在批注上会显示内容气泡（作者 + 内容）。
- **保存回文件**：工具栏「保存（未改动时变灰）」或菜单「PDF：保存」——
  先写临时文件再替换原文件；「另存为…」在保存按钮的 `▾` 里。改过没保存时标签会带脏标记。

### 5.4 论文速读 / 论文精读（AI）

两个按钮在**状态栏最右**，悬停有说明；正在跑的那个按钮底色点亮为强调色。

- **前置条件**：先在「设置 → 模型」里配置好默认模型（地址 + 密钥）。缺配置、缺密钥、
  或 PDF 抽不出文字（扫描件）时会明确弹提示。
- **论文速读**：篇幅克制（1500–3000 字，**不是摘要**：术语讲人话、核心公式给直觉，
  第 7 节告诉你去哪查背景）。执行上是一次调用；超长文档退化为"逐块写要点 → 汇总"两遍。
- **论文精读**：**补真的背景** —— 前置知识（是什么/为什么需要/在本文的角色）、关键引用点名
  （谁、做了什么、与本文差别）；公式用 `\(…\)` / `\[…\]` 排版并**逐符号解释**；
  必要处配 Mermaid 图（流程图 / 时序图 / 状态图 / 工作流图）。
  执行分阶段：读法地图 → 逐块精写 → 逐块审校（补丁式）→ 组装 → 缺项补全
  （保证有结构总览图与「值不值得精读 / 复现检查清单」两节）。
- **产物**：`文档\TruthPad\PDF\<PDF名>-<文档标识hash8>-speedread.md`（精读 `-deepread.md`）。
  文档标识优先取 PDF 内嵌的 `/ID`（增量更新 —— 加批注、加书签、加标记 **不会**改它），
  没有 `/ID` 时用「页数 + 页面尺寸 + 标题/创建日期」的指纹代替。
  **同一份文档内容不变，换个文件名也认得出**（已有稿直接打开，0 次调用）。
- **跑的时候**：状态栏状态区显示转圈 + 阶段文案 +「已用 m:ss」；正在写的稿子会实时刷新到
  右侧「预览」页签（标题带「正在生成…」）；完成后正式产物顶替它。
- **取消 / 切换**：点**正在跑的那个**按钮 = 取消（协作式：在块/阶段边界停，当前这次模型调用
  等回包后**不落盘**）；点**另一个**按钮 = 先停当前、停稳后自动开始新模式。
- **开在哪里**：优先开在右侧「预览」页签；如果那一栏正被**另一个正在生成的任务**占着，
  不会抢，改为开在编辑区，并在状态区说明。
- **过程日志**：`%LOCALAPPDATA%\TruthPad\pdf.log`，同时进底部「输出」面板的「PDF」频道
  （每次模型调用前后都有字节数、HTTP 状态与耗时）。
- **限制**：抽取文本上限约 400 页 / 40 万字符（超出会截断并在稿子里注明）；
  扫描件（无文字层）抽不出文本，会失败并说明原因。

> 🖼️ **【插图 5-4】** 状态栏右侧的转圈 + 阶段文案；右侧预览里的精读稿（含 Mermaid 图与公式）

### 5.5 AI 配置从哪来（设置 → 模型）

- 主体是 `%APPDATA%\TruthPad\models.json`，**所有需要 AI 的插件共用这一份**
  （PDF 的速读/精读、浏览器插件的翻译与字幕成文）。
- 设置页「模型」分区里可以添加多个模型，卡片字段：**ID / 显示名称 / 厂商 / 接口地址 / 密钥**，
  外加「默认」（插件默认用哪个）、「测试」和「删除」。
  上下文 1M · 最大输出 384K 是内置的只读规格；**密钥以明文存在 models.json 里**。
- 「测试」会拿这个模型发一次最小请求，结果就地回填（✓ 连接正常 / ✗ 失败）。
- 「保存模型配置」后立即广播给已加载的插件，**不用重启**；JSON 不合法会拒绝保存（原文件不动）。
- 「用记事本打开」可以直接编辑这个文件；改完在设置页打开时会自动重读。

### 5.6 性能参数（插件配置的十项）

在插件管理页对「PDF 阅读器」点「配置」可调（除 MuPDF 缓存预算外，改完立即生效）：

| 配置项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| MuPDF 缓存预算 | 32 MB | 4–1024 | 每个文档的 MuPDF store 预算；只对下一个打开的文档生效 |
| 翻页时缓存收缩 | 50% | 0–90 | 翻到新页时把缓存收缩到当前大小的百分比（0 = 不收缩） |
| 页位图内存预算 | 64 MB | 8–2048 | 已渲染页面位图的上限；超了丢最久未用的，当前页永远不丢 |
| 页位图缓存条数 | 8 页 | 1–128 | 默认≈当前页 + 前后各一页的滚动预取 |
| 显示列表缓存条数 | 3 页 | 1–64 | 每页解析出的显示列表留几份 |
| 整页渲染像素上限 | 12 MP | 1–256 | 超过就改渲可见横带（内存从页面积降到视口面积，清晰度不变） |
| 打开时解析页数 | 32 页 | 1–4096 | 打开时先真算这么多页的尺寸，其余按 Letter 估算、滚到附近再补 |
| 页尺寸补算批量 | 32 页 | 1–4096 | 滚到未解析页附近时一次补算多少页 |
| 条带渲染余量 | 1 个视口 | 0–8 | 条带渲染在可见区上下各多渲的余量 |
| 缩略图缓存条数 | 40 页 | 0–1000 | 左栏缩略图缓存几张；0 = 不缓存 |

## 6. 内置浏览器

### 6.1 打开与界面

- **入口**：标题栏右侧的「浏览」按钮，或菜单「工具 → 打开内嵌浏览器」。一个浏览器视图 =
  编辑器里的一个标签页（视图内没有自己的标签栏）；页面的标题会自动回填到标签标题。
- **顶部条**（5 个图标按钮 + 地址栏）：后退（能退才亮）、前进、刷新、**字幕**、**运行 JavaScript**，
  右侧是占满余宽的地址栏。
- **地址栏**：聚焦弹出自动完成（最多 8 条，历史优先，其次是常用网站域名）；回车导航时 ——
  带协议的网址原样打开、Windows 路径（`C:\…` 或 UNC）转成 `file://`、其余补 `https://`。
- **起始页**（新标签页）：搜索框（非网址时走 Google 搜索）、「最近常访问」、「常用网站」，
  跟随界面主题与语言。跳过起始页：直接在地址栏输入。
- **链接行为**：`target="_blank"`、`window.open` 和中键点击都会**开一个新的浏览器标签**，
  不会把当前页顶掉。

### 6.2 浏览与增强

- **广告过滤**（默认开，请求级）：内置一批广告/追踪域名，命中直接返回空白（请求不落网）；
  「额外拦截的域名」可以追加（逗号或换行分隔，子域名也算）；「记录拦截日志」会在日志里打
  「广告过滤：已拦截 N 条」。
- **页面净化**（默认开）：注入一段保守的 CSS 藏掉广告位（不碰弹幕和正片），
  并在 YouTube 出现广告时自动点「跳过广告」。
- **页面脚本注入**（总开关，默认开）：关掉后不再往网页注入任何脚本 ——
  **字幕与用户脚本会一起停用**。
- **用户脚本**（默认关）：指定一个 `.js` 文件，每次打开网页自动注入（像迷你油猴）；
  「生效域名」用逗号分隔的子串匹配（例 `bilibili.com,youtube.com`），留空 = 所有站点。
- **运行 JavaScript** 对话框（顶部第 5 个按钮）：输入一段 JS，「运行一次」作用于当前页面，
  「保存为自动注入」写进上面的用户脚本文件。
- WebView2 起不来时内容区会显示错误信息（通常意味着需要安装 Microsoft Edge WebView2 Runtime）。

### 6.3 字幕：为视频生成中文字幕

**支持情况**：bilibili 是完整链路（分 P、BV 号、断点续传都支持）；任意含 `<video>` 的页面走通用兜底；
YouTube 是**实验性、当前搁置**的采集线。

**第一次使用准备**：

- **识别模型**：在插件设置（或字幕设置弹窗）里点「下载识别模型」，默认 `large-v3-turbo`
  （约 1.6 GB，质量/速度最均衡，可选 tiny.en / base.en / small.en / medium.en）；
  下载源可选 `huggingface.co` 或 `hf-mirror.com`。模型存在 `%LOCALAPPDATA%\TruthPad\asr`。
- **DeepSeek 密钥**：**Shift + 点顶部的「字幕」按钮**打开字幕设置，把 `sk-…` 填进输入框点「保存」
  （密钥只用来把字幕**文本**发去翻译，**音频不出本机**，key 在本机用 Windows DPAPI 加密保存）。

**生成字幕**：打开视频页，点「字幕」。按当前状态它会是下面之一：

- 还没装模型 → 弹出字幕设置，让你先下载模型（不开始）；
- 没有密钥 → 只生成字幕、不翻译，并在字幕栏常驻提示；
- 这一集正在生成 → 提示你稍等（要重来走右键菜单「重新生成字幕」）；
- 这一集**已经完整生成过** → 直接显示，**不重新生成**；
- 只转了一部分（比如中途离开过）→ **续转**：从覆盖点接着转，前面转好的不重做；
- 音频临时文件还在且覆盖够 → 直接复用音频，从还没转的那段继续。

**过程中的字幕栏**（浮在网页上方，不吃网页高度）：

- 原文行 + 中文行（音频本来就是中文时只显示一行，且只做校对不翻译）；
- 生成期间中文位显示进度：「⏳ 阶段… 细节 百分比（已用 N 秒）」；
- 右下角有「n / N」读数，整集审校完成带「✓」；覆盖不足会常驻一行「⚠」警告；
- **上下拖动字幕栏**可以改它的停靠位置（位置自动记住）；
- **右键菜单**：复制当前这一句 / 生成文章（已生成过时是「查看文章」+「重新生成文章」）/
  重新生成字幕（还没字幕时是「生成字幕」）/ 字幕设置 / 关闭字幕。

**字幕设置弹窗**（Shift+点「字幕」按钮，或右键 →「字幕设置」）里还能改：

- **文件与缓存**（都在本机）：模型信息与「打开模型文件夹 / 删除模型 / 下载模型」；
  字幕缓存信息与「打开缓存文件夹 / 清空字幕缓存」；临时文件与「打开临时文件夹 / 清理临时文件」；
- **字幕外观**：原文颜色 / 中文颜色 / 背景颜色（`#RRGGBB` 输入框 +「取色…」色块按钮）、
  背景不透明度滑块、**五套一键配色**（YouTube 经典 / 电影·黄字黑底 / 描边白·透明底 /
  浅色主题 / 高对比·黄底黑字），点一下立即生效；
- **「文章实时渲染」勾选框**（默认关，见 6.4）。

**把句子带进笔记**：全局热键 **`Ctrl+Alt+S`** 把当前句按「插入笔记的格式」
（双语 / 仅译文 / 仅原文）插到编辑器的插入点。

**导出**：插件配置页的动作按钮「**复制整集 SRT**」（标准 SRT 时间轴，双语行）
与「**复制整集双语文本**」（一行原文、一行中文，中文音频只有中文）—— 走剪贴板，不落盘。

**缓存与临时文件**：

- 字幕缓存 `文档\TruthPad\Browser\subs\<站点>_<视频>.json`（原文 + 译文；每段转完即写，
  中途关掉也不丢已转好的部分）；
- 临时音频 `%TEMP%\tp-browser`（按视频身份命名，供续传/复用；可设「临时文件保留天数」
  或随时「清理临时文件」）。

**中断语义**：关标签、点链接离开、切到别的视频都会停止正在跑的任务（当前这次模型调用跑完为止），
下次进入这一集会接着生成。

### 6.4 字幕 → 文章（生成讲义）

- **入口**：字幕栏右键 →「生成文章」；已有成品时是「查看文章」（直接打开，0 次调用）+
  「重新生成文章」。
- **写作风格**（插件配置「文章风格」）：**自动判别**（默认，先抽样判读内容类型，
  认不出来按学术讲义处理）/ **学术讲义** / **小清新** / **新闻纪实**。
- **流程**（用户视角，字幕栏里的进度行会逐步显示）：

  1. **判读内容类型**（自动风格时，一次抽样调用）；
  2. **写骨架**：文档标题、全篇符号约定、各小节标题 + 时间段 + 要点 + 公式概要；
  3. **逐节写正文**：按骨架时间段切字幕写全，带着上一节结尾做衔接；
  4. **逐节审校**：对着骨架和字幕查漏、把口语改成书面、公式规范化、修画不出来的图；
  5. **写概述与总结**，然后组装成「概述 → 各节 → 总结」的总分总结构，最后做全篇硬检查。

- **产物**：`文档\TruthPad\Browser\<视频标题>-<风格>.md`（固定名，**重新生成即覆盖**；
  UTF-8 带 BOM + CRLF）。中途的进度检查点存在 `Browser\articles\<key>.json`。
- **断点续生成**：中途取消或程序退出后，再点「生成文章」会**从没写完的那一节接着写**，
  已写好的小节不再调模型；整篇写完的再点就是 0 次调用直接打开。
- **实时渲染**（默认关）：勾上「文章实时渲染」后，从骨架阶段起就在右侧「预览」页签边写边显示
  （长文刷新可能有点卡，所以默认关）。关着的时候不写半成品文件、右栏不动。
- **完成后的打开位置**：优先开在右侧「预览」页签；如果那一栏正被别的**正在生成**的任务占用，
  不会抢占（提示「右栏正被别的任务占用…」），文章照常写完，之后用右键「查看文章」打开。
- **写作规范要点**（插件内置的硬约束，生成的稿子都遵守）：
  - 公式**只用** `\(…\)`（行内）与 `\[…\]`（独立成行）—— 出现 `$…$` 会自动返修；
    正文小节不允许出现代码围栏之外的 `$`；
  - **每一级标题都带时间戳**（可以从稿子对回视频时间）；
  - 篇幅**不少于字幕字数的 2.6 倍、不设上限**（宁可长不许缩，但禁止注水与重复）；
  - 配图优先用内联 Mermaid（纯文本、预览原生渲染）；确需真实图片且有把握的公开直链才内联，
    不做本地图片、不做 base64 / 内联 SVG。

### 6.5 浏览器插件的配置项

在插件管理页对「浏览器」点「配置」：

- **信息与动作（11 项）**：模型文件位置（信息）、**下载识别模型**、打开模型文件夹、删除模型文件、

  识别线程数（8）、切块时长（45 秒）、整篇审校（开）、字幕显示（双语 / 仅译文 / 仅原文）、
  字幕字号（16）、插入笔记的格式（双语）、背景不透明度（75）、原文颜色（`#FFFFFF`）、
  中文颜色（`#6CB6FF`）、字幕区背景颜色（`#000000`）、字幕停靠位置（100 = 贴底）、
  字幕对齐（居中）、模型下载源（huggingface.co）、临时文件保留天数。
- **文章（3 项）**：文章风格（自动判别）、文章每段字幕条数（180，范围 40–400）、
  文章实时渲染（关）。
- **广告（4 项）**：广告过滤（开）、页面净化（开）、额外拦截的域名（空）、记录拦截日志（开）。

绝大多数改动**即时生效**（字幕外观每次绘制现读设置）。

### 6.6 已知限制

- **YouTube 采集是实验性的、当前搁置**：YouTube 的直链音频重放会被 403，
  只有页内 MSE 捕获这条路可用；bilibili 之外的站点请以通用兜底（任何含 `<video>` 的页面）为预期。
- 网页区域没有自定义右键菜单（用 WebView2 自带的那一套）。
- 中文音频只显示一行字幕、且只做校对（这是设计如此，不是缺功能）。
- 字幕生成的质量取决于音频与模型：`tiny.en` 快但错得多，`large-v3-turbo` 是默认的平衡点。
- 若插件清单里的说明文字与实际路径不一致，**以实际路径为准**：
  字幕缓存实际在 `文档\TruthPad\Browser\subs`（不是 `%LOCALAPPDATA%`）。

## 附录 C 常见问题

- **右键打开文件不是极简模式？** 关联命令被改过。菜单「帮助 → 修复右键打开关联」修一下
  （只写当前用户）。
- **Markdown 预览打不开 / 一片空白？** 预览依赖系统的 Microsoft Edge WebView2 Runtime；
  装一下再试（预览区会给出同样的提示）。
- **PDF 里按 `Ctrl+F` 没反应？** 那个快捷键是编辑器查找的；PDF 用工具栏「查找」按钮或
  「PDF：查找…」菜单。
- **模型卡片「测试」失败？** 检查接口地址（要 OpenAI 兼容的 `/chat/completions` 地址）
  与密钥；保存前 JSON 不合法会被拒绝（原文件不会被动）。
- **速读/精读点了没开始？** 多半是三种情况之一：没配默认模型、模型没填密钥、
  或这份 PDF 是扫描件（没有文字层，抽不出文本）—— 三种都会弹明确提示。
- **字幕只有原文没有中文？** 说明还没配 DeepSeek 密钥（或用的是中文音频，那本来就只有一行）。
  配好密钥后重新点「字幕」即可接着翻译。
- **字幕生成很慢？** 识别在本机跑：模型越大越准也越慢；可换小模型、或调「识别线程数」。
  超长视频会分段边收边转，前几分钟的字幕很快就能看到。
- **生成的文章/速读稿没弹到右边？** 那一栏可能正被另一个**正在生成**的任务占着（不会互相抢占）。
  等它跑完，或去任务自己的入口（右键「查看文章」/ 再点一次「速读」）打开。
- **导出的 HTML 打开没有目录侧栏？** 设计如此：导出的 HTML 是**单文件静态页面**，
  不含页面脚本；要看目录侧栏在编辑器里预览。
